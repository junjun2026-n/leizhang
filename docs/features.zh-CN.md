# 功能与验收范围

## 定位

本项目从零实现独立 Python / PostgreSQL SSH 堡垒机，不是 JumpServer 或其他商业产品的完整替代。0.1.0 提供可测试的核心实现；不能将代码创建、单元测试或 Docker 配置等同于已经通过生产安全评审和验收。

| 能力 | 当前实现 | 限制 |
| --- | --- | --- |
| 用户认证 | 密码、可选 MFA、注销、密码修改、数据库失败限流 | MFA 默认关闭，由管理员后台手动绑定并启用；暂无 LDAP / AD / OIDC / SAML |
| 角色与权限 | 自定义角色、逐功能查看与操作权限分配、HTTP / WebSocket 校验；按用户 / 资源系统账号限时授权 | 暂无组织树、用户组；单用户使用一个角色 |
| 用户管理 | 创建、角色调整、停用、CLI MFA 恢复 | 无自助注册；不物理删除历史用户 |
| 资产管理 | 创建、修改、启停、标签；同一资源多个独立系统账号，支持启停、删除及凭据修改 | 账号需管理员手动录入，未实现账号发现或在目标系统创建用户 |
| 凭据 | 密码、无口令私钥；Fernet 加密 | 暂无 KMS / HSM、凭据自动轮换、SSH CA |
| 主机身份 | 默认允许账号密码连接，按资产可开启可信主机公钥校验 | 开启后公钥必须通过可信渠道核验，未知或变更即拒绝；已有资产保留原校验设置 |
| 审批 | 按具体系统账号指定审批人、限时审批，禁止自己审批自己；站内小喇叭及通过／不通过消息 | 无定时推送、多级审批或外部工单对接 |
| SSH | 网页交互终端、并发及时间限制；按角色和用户启用黑／白名单受控命令模式 | 暂无原生 SSH 网关入口；受控模式不支持交互程序及任意 shell 语法 |
| 审计 | 操作日志、终端输出录像、回放及读取留痕；受控 SSH/TELNET 逐条命令记录 | 普通交互终端不提供完整结构化命令审计；TELNET 转发成功不表示执行成功 |
| 防修改 | PostgreSQL 触发器、运行账号限制 | 数据库超级管理员仍可绕过；无外部 WORM |
| 在线管控 | 终止、撤权、停用检测，约一秒检查周期 | 单实例；服务重启会断开 SSH 连接 |
| 文件传输 | 未实现 | 不提供 SFTP / SCP 文件管理及文件审计 |
| SQL | PostgreSQL、MySQL/MariaDB 网页控制台、执行前后加密审计 | 不审计外部原生客户端流量；尚未支持 Oracle / SQL Server |
| 桌面协议 | VNC 默认本机直连；RDP 使用 Guacamole；画面录像与回放 | VNC 原生协议与三页签已测试；RDP 需部署 guacd，实际业务桌面需验收 |
| TELNET | 网页终端、常见提示自动登录、加密录像 | 上游明文通信；特殊提示和多轮认证需适配 |
| HTTP / HTTPS | 隔离浏览器画面、同源访问、请求元数据审计和加密录像 | 不支持跨站资源、WebSocket、下载及弹窗 |
| 高可用 | 未实现 | 禁止多 worker、多副本运行；无灾备自动切换 |
| 运维 | Docker、迁移、健康检查、备份指引 | 生产证书、备份调度、监控平台需部署者配置 |

## 安全验收重点

- 密码使用 Argon2id；MFA 验证码只允许消费一次。
- Cookie HttpOnly、SameSite Strict，生产必须 Secure / HTTPS；变更请求验证 Origin，HTTP 校验 Host，WebSocket 单独校验 Origin。
- WebSocket 不将密钥放入 URL。连接票据 30 秒过期、一次性消费、绑定当前登录用户。
- 禁止代理转发、自动接受 SSH 主机身份、将上游凭据返回浏览器。
- 访问前与连接中持续检查账号、登录、授权、审批和资产启用状态。
- 输出先加密写入数据库，再发送到浏览器；录制持久化失败即停止会话。
- SSH 会话与系统登录有明确超时，默认每用户最多五个活动或待建立会话。
- 录像可能包含敏感业务输出及远端回显，应按敏感数据管理。
- 命令黑／白名单控制受控 SSH/TELNET 会话提交的命令，不能判断程序内部行为或替代目标系统权限；不等同于文件外传控制或完整 DLP。使用步骤见[详细使用手册](user-guide.zh-CN.md)。

## 投产前仍需执行

使用实际基础设施执行 HTTPS / WebSocket、网络隔离、数据库最小权限、备份恢复、审计留存、依赖漏洞扫描、渗透测试、并发压力及容量测试。确认功能矩阵满足实际业务，否则应补齐能力后再验收。
