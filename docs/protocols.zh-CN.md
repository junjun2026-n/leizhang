# SQL 审计与多协议资源

管理员在“资产管理 → 新增资产”选择协议，再配置系统账号，沿用账号授权、访问申请和审批流程。已有资产保持 SSH，不能直接更改协议，以免混淆历史会话和账号；需要其他协议时新增资源。默认端口：SSH 22、TELNET 23、RDP 3389、VNC 5900、HTTP 80、PostgreSQL 5432、MySQL/MariaDB 3306。HTTPS 请手动选择 HTTPS 并填写对应端口。

## PostgreSQL / MySQL / MariaDB

填写目标数据库名称、地址和目标库中已存在的系统账号。点击“连接”打开网页 SQL 控制台，每次执行一条语句，写入操作立即提交；应按业务需要使用只读或受限数据库账号。执行超时上限 30 秒，结果最多显示 500 行、约 1MiB；错误后 PostgreSQL 可继续执行，MySQL 连接关闭以免重用失效连接。

每条 SQL 在执行前加密记录，结束后追加结果、耗时、影响行数或错误，两条记录通过“关联操作”匹配。管理员和审计员在“SQL / 协议审计”查看，或在“会话与录像”选择某次 SQL 会话。审计表禁止更新、删除及清空，读取审计也会留痕。SQL 审计记录不存储查询返回数据。

审计范围为**通过本平台控制台执行的 SQL**，不包含外部原生客户端流量、目标数据库内部作业或其他应用 SQL。连接中断时数据库可能已提交操作；出现中断记录后应核实目标库结果，不能直接假设已回滚。

默认校验证书。PostgreSQL 使用 verify-full；MySQL 使用系统信任 CA 并校验主机名。自签名环境需安装可信 CA，或由管理员按实际环境关闭校验。

## RDP / VNC

VNC 默认由堡垒机直连目标，无需 guacd；SSH 弹窗增加 VNC 页签。详见 [SSH / SFTP / VNC](sftp-vnc.zh-CN.md)。以下网关配置适用于 RDP 和可选的 VNC_BACKEND=guacd 模式。

服务器需要运行 Apache Guacamole **guacd**。Compose 已包含 `guacamole/guacd:1.6.0`，应用通过内网连接，不向客户端发布 4822 端口。独立运行时设置 `GUACD_HOST`、`GUACD_PORT` 并重启应用；网关所在主机必须能连接目标资源。guacd 不提供本平台身份认证，必须将其置于可信隔离网络，禁止公开暴露。

RDP 可填写 Windows 域，使用资源账号密码登录；默认校验目标证书。VNC 的密码及是否使用用户名取决于目标服务认证方式。网页画面经过加密录像，可按原始时间回放。关闭剪贴板、文件盘映射、打印和音频转发。

RDP 和可选的 VNC 网关模式需要可连接的 guacd。默认 VNC 原生模式无需该网关，浏览器通过堡垒机连接 Linux VNC 桌面；目标需启动兼容的 VNC 服务并放行堡垒机访问其端口。

## TELNET

使用目标设备已存在的账号密码，识别常见 login / username / password 提示并登录，终端输出加密录制。定制认证提示、多轮认证需按设备适配。TELNET 上游通信为明文，应仅用于受控网络中的兼容设备。

## HTTP / HTTPS

平台服务器启动独立浏览器上下文，将画面传给用户，目标页面脚本不在堡垒机网页源执行。Windows 默认使用本机 Microsoft Edge；Linux/Docker 使用 Playwright Chromium，Dockerfile 自动安装。独立 Linux 环境安装依赖后运行 `python -m playwright install --with-deps chromium`。Windows 可通过 `HTTP_BROWSER_CHANNEL` 指定已安装的浏览器通道。

资源账号用于 HTTP Basic 认证；表单登录可在远程画面手动输入。点击画面操作，键盘输入或通过“发送文字”粘贴中文。仅允许当前资源的同源请求，阻断外站、WebSocket、弹窗及下载；依赖外部 CDN、第三方登录、WebSocket 的站点可能无法使用。HTTP 不支持通用反向代理、文件传输或原生浏览器标签页。

审计记录请求方法、URL、响应状态；URL 查询参数隐藏，不记录请求体、Cookie 和认证头。变更画面先加密保存再发送，截图可能包含业务敏感数据。会话默认录像容量 20MiB，动态页面可能较快达到上限，可按留存容量调整 `MAX_RECORDING_BYTES`。

所有协议保留登录有效期、账号授权、审批期限、并发限制、空闲和总时长检查，撤权、停用或强制终止后关闭连接。单实例部署；重启会中断活动会话。
