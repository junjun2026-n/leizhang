# SSH / SFTP / VNC 三页签

## SSH 与 SFTP

在“资源管理 → 资产管理”选择 SSH 资源，点击“连接”并选择已授权系统账号。连接窗口提供三个 Sheet（页签）：

- **SSH 终端**：默认打开，提供原有终端及录像。
- **SFTP 文件**：第一次切换时建立单独的文件会话，可输入远程目录、浏览目录、返回上级、新建目录、上传和下载文件。切回终端不会断开文件会话。
- **VNC**：选择已配置的 VNC 资源和系统账号，点击“连接 VNC”；同主机的 VNC 资源优先排列。切换页签保留各自连接，右上角 × 同时关闭三类连接。

目标 SSH 服务必须启用 SFTP 子系统。文件操作使用所选系统账号，受目标文件系统权限限制；平台资源账号授权、指定审批、登录状态、角色连接权限、会话时长和空闲超时继续生效。SFTP 不需要额外开放文件传输端口，通常与 SSH 同为 22。

每个文件最大 20 MiB，目录列表最多 2000 项。上传不覆盖同名文件，遇到同名请修改本地文件名后上传。传输中关闭窗口会中断；未完成上传可能留下不完整文件，请在目标端核查。

角色或用户启用了 SSH/TELNET 命令黑／白名单时，SFTP 被拒绝，避免通过文件操作绕过命令限制。需要文件传输时，请为适当用户配置不受命令策略限制的角色，并限制目标系统账号的文件权限。

关闭右上角 × 同时关闭 SSH 与 SFTP。两者在会话列表中各有独立记录；SFTP 对应 SSH 协议会话，文件操作记录在“审计 → SQL / 协议审计”，协议筛选选择 SSH。记录包括目录读取、创建目录、上传／下载请求与结果、路径、字节数和 SHA-256；审计详情加密保存。文件内容不保存为终端录像。

## VNC

### 从 WEB 连接 Linux 桌面

1. Linux 目标必须已安装桌面环境及 VNC 服务（例如 TigerVNC）。仅开放 SSH 的 Linux 主机不能直接显示桌面。
2. 启动目标 VNC 桌面并设置 VNC 密码。显示号 `:1` 通常对应 TCP `5901`，`:2` 对应 `5902`；请使用目标实际监听端口，不要默认所有主机都是 `5900`。
3. 确认堡垒机服务器能访问该地址和端口。只监听 `127.0.0.1` 的 VNC 服务无法通过目标主机 IP 连接；可配置受控业务地址监听并仅放行堡垒机来源，或事先建立受控隧道。浏览器只连接堡垒机 WEB 地址。
4. 资产管理新增 VNC 资源，填写 Linux IP、实际 VNC 端口，系统账号使用目标 VNC 服务要求的账号及 VNC 密码。SSH 密码与 VNC 密码可能不同。
5. 授权并完成所需审批后，在资产列表点击连接，或在 SSH 弹窗的 VNC 页签选择资源和账号。桌面直接显示在浏览器内，可使用鼠标和键盘；点击“全屏桌面”进入全屏，Esc 退出全屏。
6. 右上角 × 关闭连接；管理员可通过会话与录像查看会话及录制的桌面画面。

默认原生连接支持的安全类型取决于 asyncvnc；目标强制使用不受支持的 TLS/VeNCrypt 等类型时不能仅凭开放端口连接。传统 VNC 密码认证只使用密码前 8 字节，建议在隔离管理网络中部署，并通过 HTTPS 访问堡垒机。

VNC 默认由堡垒机 Python 服务直接连接目标，不需要本机安装 VNC Viewer、Docker、WSL 或 guacd。支持画面、鼠标键盘、加密录像及回放。新增资源时选择 **VNC**，填写目标主机、VNC 实际端口（通常为 5900）和密码，再配置资源账号授权及审批。可在资产列表直接连接，也可在 SSH 弹窗的 VNC 页签选择连接。

VNC 目标是单独的资源和系统账号，不能把 SSH 密码自动当作 VNC 密码，也不能仅凭 SSH 授权访问 VNC。VNC 的连接权限、账号授权、访问审批、会话超时和撤权检查均独立执行。

默认 `VNC_BACKEND=native`，支持 RFB 3.8 的 VNC 密码认证等 asyncvnc 支持的安全类型；传统 VNC 密码认证只使用前 8 字节密码。目标使用仅支持其他安全类型的配置时需调整目标或使用兼容网关。桌面最大 4096 × 2160，画面以 JPEG 传输和录制，不提供剪贴板、音频或文件盘映射。录像继续受 `MAX_RECORDING_BYTES` 限制。

RDP 仍需 Guacamole 网关；既有 Guacamole VNC 录像可以继续回放。若需要旧的 VNC 网关模式，可配置 `VNC_BACKEND=guacd` 并设置 `GUACD_HOST`、`GUACD_PORT`，资产列表的 VNC 连接会使用网关；SSH 的 VNC 页签用于默认原生模式。

已验证本机原生 RFB 测试服务的密码认证、画面解码、键鼠输入、错误密码拒绝和加密录像；实际业务桌面还需使用目标主机配置验证。
