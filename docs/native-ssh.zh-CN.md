# 原生 SSH 客户端接入

在资产管理中选择 SSH 资源的「SSH 客户端」，选择授权系统账号。页面显示连接命令和临时票据。运行命令，在密码提示中粘贴票据。先在网页完成登录（启用 MFA 时也需完成 MFA）和审批；不接受直接使用平台密码或资源密码登录此入口。

票据有效期 30 秒，仅允许启动一个交互会话，绑定当前登录、资源和系统账号；退出平台、禁用用户、撤销授权、审批过期会关闭连接。票据不得转发他人，勿放入命令行参数、日志或脚本。超时需重新生成。

默认监听 `0.0.0.0:2222`，网页管理仍使用 `8200`。环境变量 `SSH_PROXY_PORT=0` 关闭入口，`SSH_PROXY_HOST` 修改绑定地址，`SSH_PROXY_KEY` 指定持久化主机私钥路径。默认私钥为 `runtime/ssh-proxy-key`，首次启动自动生成，需限制文件权限并备份。首次连接必须核对主机指纹，可在服务端执行 `ssh-keygen -lf runtime/ssh-proxy-key`。

Docker Compose 将私钥保存在独立卷 `ssh_host_key`，默认发布 `2222`。若修改容器监听端口，应同步修改 Compose 端口映射。仍只支持单实例/单 worker；不要多个实例共享同一数据库运行会话网关。

交互会话复用网页终端的账号授权、审批、5 会话限制、命令黑白名单、加密输出录像、超时和管理员终止。已配置命令策略时进入受控命令终端。无命令策略时保存终端输出录像，不保证逐条解析 shell 命令。当前不支持 exec、原生 SFTP/SCP、隧道、代理转发或 X11；网页 SFTP 功能保持可用。上游终端初始尺寸为 100×30，客户端调整窗口时同步尺寸。

本次完善仅增加原生 SSH 入口。原生 PostgreSQL/MySQL 代理、OIDC/LDAP、S3 录像与多节点网关仍未实现；网页 SQL 控制台不等于原生数据库协议代理。
