# 角色与命令黑／白名单

平台菜单与操作权限可在“权限管理”中按角色逐项分配，详见[平台权限管理](permissions.zh-CN.md)。下文管理员、运维人员、审计员为默认权限类型；自定义平台权限后，以实际已分配权限为准。

管理员登录后进入“角色管理”，可新增、编辑和删除自定义角色。角色名称、说明和 SSH / TELNET 命令规则可以编辑；权限类型选择管理员、运维人员或审计员，沿用平台已有的资源授权、审批与审计权限边界。内置角色不可删除、不可改变权限类型。被用户使用的自定义角色不可删除。

在“用户管理 → 角色 / 启停”分配角色。在“用户管理 → 命令黑 / 白名单”配置用户自己的规则；该窗口也会展示所属角色规则。不能修改自己的角色或停用自己的账号。

命令策略默认不限制，保留原有交互终端。选择黑名单或白名单后，仅 SSH / TELNET 使用受控逐条命令终端，SQL、RDP、VNC 和 HTTP 不受命令策略影响。

规则每行一条，区分大小写，支持 `*`、`?` 和字符组通配符。例如：

```text
rm
reboot
shutdown *
```

黑名单命中即拒绝。单独的命令名称（例如 `rm`）匹配该命令及其全部参数，也匹配 `/bin/rm`。带参数的规则匹配完整命令。白名单示例：

```text
whoami
hostname
ls -l /var/log
df -h
```

角色规则和用户规则共同生效：任何黑名单命中都拒绝；每一份启用的白名单都必须匹配。白名单为空时拒绝全部命令；黑名单为空无法保存，请改选“不限制”。用户选择“不限制”不会取消角色限制。

受控模式在服务端缓冲输入，整条命令检查通过后才发往目标。拒绝控制符、管道、重定向、变量与命令替换，不转发历史键、补全和终端控制序列。解释器、交互编辑器和常见命令代理被禁用，即使白名单包含它们也不放行。命令参数以字面值传递，不能依赖远端 shell 展开 `*`。SSH 每条命令使用独立的非交互执行通道，不保留 `cd`、环境变量等状态，单条命令最长执行 60 秒。TELNET 保留目标设备环境，自动登录完成并识别 `$`、`#` 或 `>` 提示符后才允许发送命令；设备应使用可识别的标准提示符。

保存用户策略、修改角色策略会终止对应用户的现有 SSH / TELNET 会话（包括待连接票据），重新连接生效。修改角色的权限类型会同时终止对应用户的所有协议会话并注销其登录。单独修改角色名称或说明不会终止会话。

“命令审计”展示命令申请、拒绝、SSH 执行结束状态以及 TELNET 转发记录，记录操作者、资源、系统账号和命令。TELNET 的转发成功表示命令已发送，不表示远端执行成功；执行输出需结合会话录像查看。只有管理员和审计员可查看命令审计。只有受控模式记录这些逐条命令事件；不限制模式继续保存终端录像。

这些规则控制网关提交的命令，无法判断程序内部行为，也不能替代目标系统权限。用户自建程序、脚本、复制改名的程序、远端别名和远端 shell 启动文件，均需要在目标系统中限制。严格权限场景应使用精确白名单、权限受限的专用系统账号及目标系统的文件和执行权限；不要将任意程序或宽泛的 `*` 当作安全隔离。
