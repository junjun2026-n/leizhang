# 平台用户与资源系统账号

平台用户在“用户管理”中创建，用于登录堡垒机、权限判断、访问审批和操作审计。资源系统账号在“资产管理”中配置，例如服务器上的 `root`、`ubuntu` 或 `tester`，由堡垒机使用其单独保存的密码或私钥建立 SSH 连接。

两类账号的用户名和密码互不要求一致；修改平台登录密码不会修改资源密码。资源凭据加密保存，资产查询接口不返回凭据，授权用户无需知道目标服务器的密码。

## 同一资源授权多人

1. 管理员在“资产管理”中录入一次资源地址、端口、系统账号及凭据。
2. 在“资产授权”中选择此资源和具体系统账号，勾选一个或多个平台用户，设置有效小时后保存。
3. 用户各自登录堡垒机，从“资产管理”中访问已授权资源。需要审批的资源仍须每个用户单独申请并获得审批。

每份授权对应一个平台用户和一个资源系统账号，不存在资源所有者独占关系。重新保存只更新所选账号授权的有效期；撤销只终止该用户使用该账号的会话，不影响其他账号及其他用户。

管理员可以直接访问启用的资源；审计员不能通过授权获得 SSH 运维权限。停用的平台用户不能新增或续期授权。

“资产授权”的平台用户列表显示全部用户：已启用的管理员和运维用户可勾选，停用用户和审计员显示不可选原因。“全选”仅选择可授权用户，页面显示可授权人数和已选人数。只有管理员账号时也可以选择；管理员已有全局访问权限，如需验证普通用户的账号范围限制，请在“用户管理”中创建运维用户后单独授权。

## 选择访问审批人

资源开启“需要审批”后，用户在“资产管理”点击“申请访问”，选择系统账号、审批人，填写原因和访问时长。审批人只能选择其他已启用的管理员，不允许自审。提交后自动显示“访问审批”列表，指定审批人登录后在该菜单通过或拒绝申请；其他管理员可以查看，但不能代替指定审批人处理。通过后申请用户可连接对应系统账号，仍需满足账号授权及审批有效期。

只有一个管理员时，普通运维用户可以选择该管理员审批；该管理员本人申请则没有其他审批人，需要先新增另一个管理员。没有审批人时页面会明确提示，不会提交无法处理的新申请。升级前没有指定审批人的历史申请仍由任一其他管理员处理；审批人停用或失去管理员角色后，申请用户需要向当前可用管理员重新申请。

每个 SSH 会话归属于实际发起连接的平台用户。会话保存连接时的资源系统用户名快照，后续修改账号名称不会改写历史会话身份。录像和审计以平台用户及其独立会话记录。即使多人使用同一服务器系统账号，也可在堡垒机区分各自会话。共享系统账号在目标服务器上仍是同一操作系统身份，服务器本地日志的区分能力取决于服务器本身。

## 同一资源多个系统账号

管理员可直接进入左侧“系统账号”菜单集中管理。页面顶部“新增系统账号”先选择所属资源，再录入账号；也可从“资产管理”顶部的“系统账号管理”进入。支持按资源、状态、账号、地址及授权用户名筛选，表格展示有效授权人数和平台用户。修改、启停及删除后列表自动刷新，授权按钮会选中对应资源与账号。“授权用户”查看该账号的有效和已过期授权。

1. 进入“资产管理”，点击资源行的“系统账号”。
2. 点击“新增系统账号”，填写目标服务器上已有的用户名、密码或未加口令的 SSH 私钥。系统不会自动在远程服务器上创建用户。
3. 在账号行点击“授权”，或进入“资产授权”选择资源、具体系统账号和平台用户。
4. 用户登录后只看到自己有权使用的账号。一个资源有多个可用授权账号时，点击连接或申请访问会先选择系统账号；只有一个可用账号时直接使用该账号。

例如同一个资源可以添加 `root`、`developer`、`ops`：只把 `developer` 授权给开发人员，把 `ops` 授权给运维人员。给用户授权 `developer` 不会使其获得 `root` 的连接权限。

密码和私钥按账号分别加密保存，读取接口不返回凭据。管理员可修改、停用、启用和删除账号；停用、修改用户名或更换凭据会终止该账号的现有会话。删除会撤销该账号全部授权及未结束审批、终止对应会话并清除凭据，保留历史会话、审计和录像。重新添加同名账号不会恢复此前授权。

访问审批绑定具体系统账号，一个账号的审批不能用于另一个账号。账号级撤权同时作废该用户对此账号未结束的审批，重新授权后需要重新审批。

升级至迁移 `0005` 时，原有每个资源的用户名和加密凭据迁移为该资源的初始系统账号，原有授权及审批仅关联这个原始账号，不会扩展到以后添加的账号。旧接口未指定 `account_id` 时只操作初始账号；多账号场景应明确指定 `account_id`。

旧系统账号凭据字段作为兼容镜像保留于资源记录，新增账号完全独立存储。账号删除采用保留身份记录的方式，以维持历史会话引用；已删除账号不会参与登录或账号列表。

## 筛选与批量管理

“资产授权”提供平台用户、资源、授权状态和关键字筛选。关键字可匹配平台用户名、资源名、地址和资源系统账号。列表显示有效、24 小时内到期、已过期及不可用状态；用户停用、用户成为审计员或资源停用时，未过期的授权显示为不可用。

勾选授权记录后可以批量续期、批量撤销；单次最多 100 项，可跨资源选择。全选只选择当前筛选结果，重新筛选会清空勾选。

- 批量续期：未过期授权从原到期时间增加小时；过期授权从现在开始增加小时。停用用户及审计员不能续期。
- 修改有效期：针对单条授权，从当前时间重新设置有效小时，与“增加时长”的批量续期区分。
- 批量撤销：只删除选中用户与资源之间的授权，终止这些授权对应的待连接和活动会话。其他用户、资源及会话保持原状。

批量操作先检查全部选择；任何授权不存在、已被其他管理员撤销或不符合续期条件，整批操作失败，不会只修改部分授权。操作逐条写入审计。

资源列表的“有效授权用户数”统计对启用账号拥有未过期授权的运维用户，按平台用户去重；资源是否启用另列显示。点击“授权用户”可以查看该资源的所有账号授权（包括已过期记录），并直接跳转到该资源的授权管理。普通用户的资源列表按账号显示自己的授权到期时间，不返回其他用户的授权信息。
